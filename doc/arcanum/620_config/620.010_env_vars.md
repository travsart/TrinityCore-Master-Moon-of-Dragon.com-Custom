# Environment Variables Reference

Claude Code reads 25+ environment variables for feature control, tuning, and debugging.

## Feature Toggles

| Variable | Effect |
|----------|--------|
| `CLAUDE_CODE_DISABLE_FAST_MODE` | Disable fast mode |
| `CLAUDE_CODE_DISABLE_AUTO_MEMORY` | Disable automatic memory extraction |
| `CLAUDE_CODE_DISABLE_THINKING` | Disable extended thinking entirely |
| `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS` | Disable background tasks |
| `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` | Privacy mode -- no analytics |
| `CLAUDE_CODE_DISABLE_FEEDBACK_SURVEY` | Suppress survey prompts |
| `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS` | Enable multi-agent teams/swarms |
| `CLAUDE_CODE_ENABLE_FINE_GRAINED_TOOL_STREAMING` | Stream tool execution |
| `CLAUDE_CODE_BRIEF` | Brief output mode |
| `CLAUDE_CODE_PROACTIVE` | Proactive suggestions |
| `CLAUDE_CODE_COORDINATOR_MODE` | Coordinator mode (4-tool restriction) |

## Tuning Overrides

| Variable | Default | Effect |
|----------|---------|--------|
| `CLAUDE_CODE_MAX_CONTEXT_TOKENS` | Model-dependent | Override context window (ant-only) |
| `CLAUDE_CODE_MAX_OUTPUT_TOKENS` | Model-dependent | Override max output tokens |
| `CLAUDE_CODE_SUBAGENT_MODEL` | -- | Override subagent model |
| `CLAUDE_CODE_AUTO_MODE_MODEL` | -- | Override auto-mode model |
| `CLAUDE_CODE_EFFORT_LEVEL` | -- | Effort override (low/medium/high) |
| `CLAUDE_CODE_IDLE_THRESHOLD_MINUTES` | 75 | Idle detection threshold |
| `MCP_TOOL_TIMEOUT` | ~27.8h | MCP tool execution timeout |
| `API_TIMEOUT_MS` | 600000 | Client-level API timeout (ms) |
| `CLAUDE_CODE_MAX_RETRIES` | 10 | Maximum API retry attempts |

## API & Authentication

| Variable | Effect |
|----------|--------|
| `ANTHROPIC_BASE_URL` | Override API base URL |
| `ANTHROPIC_MODEL` | Override main loop model |
| `ANTHROPIC_SMALL_FAST_MODEL` | Override small/fast model |
| `ANTHROPIC_BETAS` | Comma-separated additional beta headers |
| `ANTHROPIC_CUSTOM_HEADERS` | Newline-separated custom headers |
| `CLAUDE_CODE_EXTRA_BODY` | JSON merged into API request body |
| `CLAUDE_CODE_EXTRA_METADATA` | JSON merged into metadata.user_id |
| `CLAUDE_CODE_UNATTENDED_RETRY` | Infinite retry on 429/529 (ant-only) |

## Internal / Debug

| Variable | Effect |
|----------|--------|
| `USER_TYPE` | `"ant"` for Anthropic employees |
| `CLAUDE_INTERNAL_FC_OVERRIDES` | Feature flag overrides (ant-only, JSON) |
| `CLAUDE_ENABLE_STREAM_WATCHDOG` | Enable stream idle timeout |
| `CLAUDE_STREAM_IDLE_TIMEOUT_MS` | Stream idle timeout (default 90s) |
| `CLAUDE_CODE_DISABLE_1M_CONTEXT` | Disable 1M context (HIPAA compliance) |
| `CLAUDE_CODE_REMOTE` | Mark session as remote (disables voice) |

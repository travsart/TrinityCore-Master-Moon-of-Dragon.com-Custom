# Feature Flags & Gates

Claude Code uses a three-tier feature gating system with ~175+ total gates.

## Architecture

| Tier | Mechanism | Naming | Runtime? |
|------|-----------|--------|----------|
| Build-time | `feature('FLAG')` via `bun:bundle` | `SCREAMING_SNAKE` | No -- dead code eliminated at compile |
| Server-side | GrowthBook (migrating from Statsig) | `tengu_snake_case` | Yes -- cached, refreshed periodically |
| Environment | `CLAUDE_CODE_*` env vars | `SCREAMING_SNAKE` | Yes -- local overrides |

**"Tengu"** is the internal codename for Claude Code's flag namespace.

## GrowthBook Details

- Fetched from `api.anthropic.com` remote eval
- Cached to `~/.claude.json` under `cachedGrowthBookFeatures`
- Refresh interval: **6h** (external), **20min** (Anthropic employees)
- Targeting attributes: `id`, `platform`, `subscriptionType`, `appVersion`, `email`, `userType`

## Override Priority (highest to lowest)

1. `CLAUDE_INTERNAL_FC_OVERRIDES` env var (ant-only, JSON map)
2. `/config` Gates tab in `~/.claude.json` -> `growthBookOverrides` (ant-only)
3. GrowthBook remote eval (in-memory)
4. GrowthBook disk cache
5. Statsig disk cache (migration fallback)

## Platform Support

### macOS
- **Primary**: Native NAPI (`cpal` -> CoreAudio/AudioUnit)
- **Fallback**: SoX `rec` (requires `brew install sox`)
- **Gotcha**: `dlopen` blocks event loop 1-8s on cold CoreAudio daemon

### Windows
- **Primary**: Native NAPI (`cpal` -> WASAPI)
- **Fallback**: None -- if native fails, voice is unavailable
- **Gotcha**: Bun's ws fires `unexpected-response` for successful 101 upgrades

### Linux
- **Primary**: Native NAPI (`cpal` -> ALSA), only if `/proc/asound/cards` has entries
- **Fallback 1**: `arecord` (ALSA utils), probed with 150ms test
- **Fallback 2**: SoX `rec`
- **WSL**: WSL2+WSLg (Win11) works via PulseAudio RDP pipes. WSL1/Win10-WSL2 have no audio

### Remote / Homespace
Voice is disabled entirely when `isRunningOnHomespace()` or `CLAUDE_CODE_REMOTE` is truthy.

## Language Support

19 languages: en, es, fr, ja, de, pt, it, ko, hi, id, ru, pl, tr, nl, uk, el, cs, da, sv, no.

Language resolution checks BCP-47 codes, then name map (English + native names), then base subtag. Unsupported languages fall back to English with a warning.

## Focus Mode (Unreleased)

A passive recording mode driven by terminal focus/blur instead of key holds. 5-second silence timeout tears down idle connections. Enables "multi-clauding army" workflow. Currently hardcoded to `false`.

## Edge Cases

1. **No TTS** -- "Voice mode" means voice INPUT only
2. **Buffer copies required** -- native NAPI chunks may share pooled ArrayBuffer
3. **Zombie prevention** -- session generation counter prevents abandoned WebSockets from corrupting state
4. **Early-error retry** -- first WebSocket error triggers single retry with 250ms backoff
5. **Audio buffering during connect** -- recording starts immediately, flushed in 32KB coalesced slices when WS connects

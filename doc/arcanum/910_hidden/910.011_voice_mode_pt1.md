# Voice Mode / Push-to-Talk

Voice Mode enables spoken interaction via push-to-talk. It is **STT input only** -- no TTS or audio playback. The system captures audio, streams it to Deepgram Nova 3 via Anthropic's WebSocket proxy, and injects transcribed text into the prompt input.

## Feature Gating (Triple Layer)

| Gate | Type | Default | Notes |
|------|------|---------|-------|
| `VOICE_MODE` | Build-time | Off in external | Dead code eliminated from npm |
| `tengu_amber_quartz_disabled` | GrowthBook kill-switch | `false` | **Inverted**: true = DISABLED |
| Anthropic OAuth | Runtime auth | Required | No voice with API keys |

The positive ternary pattern is deliberate: `feature('VOICE_MODE') ? !getFeatureValue(...) : false`. A negative pattern would fail to eliminate inline string literals from external builds.

## Audio Capture Pipeline

**Format**: 16kHz sample rate, 16-bit signed PCM, mono (1 channel).

**Backend priority** (in `voice.ts`):
1. **Native NAPI** (`audio-capture-napi` via Rust `cpal` crate) -- macOS/Windows/Linux
2. **arecord** (ALSA utils) -- Linux fallback, 150ms device-open probe
3. **SoX** (`rec` command) -- Linux/macOS fallback, `--buffer 1024`

The native module is lazy-loaded on first voice keypress. On macOS, `dlopen` of `audio-capture.node` blocks the event loop for 1-8 seconds on cold CoreAudio daemon starts.

Silence detection is disabled for push-to-talk -- recording runs until key release.

## WebSocket STT Protocol

**Endpoint**: `/api/ws/speech_to_text/voice_stream` on `api.anthropic.com`

Uses `api.anthropic.com` (not `claude.ai`) to avoid Cloudflare TLS fingerprinting.

**Wire format**:
- Client -> Server: Binary PCM frames + JSON control (`KeepAlive`, `CloseStream`)
- Server -> Client: JSON (`TranscriptText`, `TranscriptEndpoint`, `TranscriptError`)

**Connection params**: `encoding=linear16`, `sample_rate=16000`, `channels=1`, `endpointing_ms=300`, `utterance_end_ms=1000`, `language=en`, plus up to 50 keyterms.

**STT Provider**: Deepgram Nova 3 (via `tengu_cobalt_frost` flag), routed through Anthropic's conversation-engine.

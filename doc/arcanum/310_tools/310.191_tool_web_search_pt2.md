## Interesting Findings

1. The search query extraction from streaming JSON is done via regex on partial JSON: `/"query"\s*:\s*"((?:[^"\\]|\\.)*)"/.exec()`. This is because the query comes through `input_json_delta` events before the full JSON is complete.

2. The model's response to a web search includes interleaved `text`, `server_tool_use`, and `web_search_tool_result` blocks. The parsing in `makeOutputFromSearchResponse` handles this interleaving with a state machine (inText flag).

3. The `extractSearchText()` returns empty string because "renderToolResultMessage shows only 'Did N searches in Xs' chrome -- the results[] content never appears on screen."

# Constants and Prompts
> Source: `02_system_prompt_assembly.md`, `19_api_layer.md`

## System Prompt Structure

Assembled by `getSystemPrompt()` in two zones separated by `__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__`:

**Static zone** (globally cacheable): identity, system rules, task execution, actions, tool usage, tone/style, output efficiency.

**Dynamic zone** (per-session): session guidance, memory prompt, env info (cwd, platform, shell, OS, model, cutoff), language, output style, MCP instructions (UNCACHED -- recomputes every turn), scratchpad, function result clearing.

## CLAUDE.md Injection

CLAUDE.md content is NOT in the `system` parameter. It is injected as the first user message wrapped in `<system-reminder>` tags with the preamble: "IMPORTANT: These instructions OVERRIDE any default behavior."

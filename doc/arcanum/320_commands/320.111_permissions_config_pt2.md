## Commands

### /permissions
- **Aliases**: `/allowed-tools`
- **Arguments**: None
- **What it does**: Opens an interactive panel for managing tool permission rules. Users can create allow and deny rules that control which tools Claude Code can use without asking for confirmation. Rules can be scoped to specific tool patterns (e.g., `Bash(git:*)` to allow all git commands).
- **Feature gating**: None -- always available.
- **Key code**:
```typescript
const permissions = {
  type: 'local-jsx',
  name: 'permissions',
  aliases: ['allowed-tools'],
  description: 'Manage allow & deny tool permission rules',
}
```
- **Notes**: This is the central security configuration point. Rules are persisted to settings files and can be scoped at user, project, or session level.

---

### /sandbox
- **Arguments**: `exclude "command pattern"`
- **What it does**: Configures sandbox (process isolation) settings for Bash commands. The command shows current sandbox status with a rich description including:
  - Whether sandboxing is enabled/disabled
  - Whether auto-allow mode is on (all bash commands allowed when sandboxed)
  - Whether unsandboxed fallback is permitted
  - Whether settings are policy-managed (locked by admin)
  - Whether required dependencies are installed

  Users can toggle sandbox on/off, configure auto-allow, and add exclusion patterns for commands that should bypass the sandbox.
- **Feature gating**: Hidden on unsupported platforms (`!isSupportedPlatform()`) or when the platform is not in the enabled list (`!isPlatformInEnabledList()`).
- **Execution**: `immediate: true`
- **Key code**:
```typescript
const command = {
  name: 'sandbox',
  get description() {
    const currentlyEnabled = SandboxManager.isSandboxingEnabled()
    const autoAllow = SandboxManager.isAutoAllowBashIfSandboxedEnabled()
    const allowUnsandboxed = SandboxManager.areUnsandboxedCommandsAllowed()
    const isLocked = SandboxManager.areSandboxSettingsLockedByPolicy()
    const hasDeps = SandboxManager.checkDependencies().errors.length === 0
    // ... builds rich status string with icons
  },
  argumentHint: 'exclude "command pattern"',
  immediate: true,
  type: 'local-jsx',
}
```
- **Notes**: The description is dynamic and updates to show current status with checkmark/circle/warning icons. Uses `SandboxManager` for all sandbox operations. This is a critical security command.

---

### /privacy-settings
- **Arguments**: None
- **What it does**: Opens a panel for viewing and updating privacy settings. Controls what data is shared with Anthropic for training and analytics.
- **Feature gating**: Only enabled for consumer subscribers (`isConsumerSubscriber()`). Enterprise and API key users have different privacy controls.
- **Key code**:
```typescript
const privacySettings = {
  type: 'local-jsx',
  name: 'privacy-settings',
  description: 'View and update your privacy settings',
  isEnabled: () => isConsumerSubscriber(),
}
```

## Hidden/Undocumented Commands

None in this group -- all three commands are visible when their feature gates are met.

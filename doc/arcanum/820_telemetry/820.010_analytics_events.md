# Analytics Events
> Source: `19_api_layer.md`, `21_feature_flags.md`

## Overview

Claude Code sends analytics events to Anthropic for product improvement. Events are logged via Statsig/GrowthBook and include session metadata, tool usage, and performance data.

## Key Event Categories

**API events**: Request success/failure, streaming stalls, non-streaming fallback, gateway detection, cache break diagnosis, retry counts.

**Tool events**: Tool permission decisions (`tengu_tool_use_granted_*`), code edit metrics with language detection, tool execution timing.

**MCP events**: Server connection success/failure, needs-auth, large result handling, claude.ai proxy 401s.

**Session events**: Session start/end, compaction triggers, cost tracking, memory extraction.

## Disabling Telemetry

| Method | Scope |
|--------|-------|
| `DISABLE_TELEMETRY` env var | All analytics |
| `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` | All nonessential network |
| `/privacy-settings` command | Consumer privacy controls |
| `CLAUDE_CODE_ENABLE_TELEMETRY` | Explicit enable |

## What Is NOT Sent

Prompts, file contents, and tool outputs are not included in analytics events. Events contain metadata: tool names, file extensions, timing, error codes, model names.

## GrowthBook Sampling

`tengu_event_sampling_config` controls sampling rates. `tengu_1p_event_batch_config` controls batching delay.

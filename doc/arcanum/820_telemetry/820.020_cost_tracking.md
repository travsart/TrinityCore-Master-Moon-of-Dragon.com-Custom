# Cost Tracking
> Source: `19_api_layer.md`

## Per-Request Cost Calculation

Cost calculated at `message_delta` SSE event using `calculateUSDCost()`:
```
costUSD = addToTotalSessionCost(calculateUSDCost(model, usage))
```

## Pricing Tiers

| Tier | Input $/Mtok | Output $/Mtok | Models |
|------|-------------|--------------|--------|
| Haiku 3.5 | $0.80 | $4 | Haiku 3.5 |
| Haiku 4.5 | $1 | $5 | Haiku 4.5 |
| Sonnet | $3 | $15 | All Sonnet variants |
| Opus | $5 | $25 | Opus 4.5, Opus 4.6 |
| Opus Fast | $30 | $150 | Opus 4.6 fast mode |

**Cache**: write = 1.25x input cost, read = 0.1x input cost. **Web search**: $0.01/request.

## Token Counting

Usage from API: `input_tokens + cache_creation_input_tokens + cache_read_input_tokens + output_tokens`. Streaming provides cumulative totals (not deltas) -- `updateUsage()` guards with `> 0` checks.

## Session Persistence

Costs saved to project config (`lastCost`, `lastAPIDuration`, `lastModelUsage`) and restored when resuming the same session.

## Advisor Cost

When the advisor tool is used, its token usage is extracted from the main response and tracked separately with its own model's pricing.

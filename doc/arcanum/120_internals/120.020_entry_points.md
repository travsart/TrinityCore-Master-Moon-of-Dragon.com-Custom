# Entry Points
> Source: `06_tool_pipeline.md`, `17_bridge.md`

## Three Entry Modes

### 1. REPL Mode (Interactive Terminal)
Default mode. React/Ink UI with prompt input, message rendering, permission dialogs. Full tool set.

### 2. SDK Mode (Headless/Programmatic)
Used by Agent SDK and `claude --print`. Runs through `QueryEngine.ts` (48KB) without UI. No interactive prompts -- uses `dontAsk` or pre-configured rules. Supports streaming via async generators.

### 3. Bridge Mode (Remote Control)
Connects to Anthropic CCR servers for remote access from claude.ai/code or mobile.
- **Standalone** (`claude remote-control`): Persistent server, up to 32 sessions
- **REPL Bridge**: Background connection in interactive session

## Mode Detection

| Flag/Condition | Mode |
|----------------|------|
| `--print` / piped stdin | SDK (headless) |
| `remote-control` subcommand | Bridge standalone |
| `/remote-control` or auto-connect | Bridge REPL |
| Default | REPL interactive |

## Tool Availability by Mode

REPL and SDK get full `assembleToolPool()`. Subagents get filtered sets (no `AgentTool`, `AskUserQuestion`). Bridge children run as `claude --print`.

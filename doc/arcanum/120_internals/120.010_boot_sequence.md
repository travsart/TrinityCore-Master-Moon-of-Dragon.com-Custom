# Boot Sequence
> Source: `06_tool_pipeline.md`, `02_system_prompt_assembly.md`

## Initialization Order

```
cli.js -> entrypoint detection (REPL/SDK/bridge)
  -> bootstrap/state.ts (global state init)
  -> setup.ts (settings load, feature flags, session ID)
  -> GrowthBook init (~5s first fetch, cached after)
  -> initBundledSkills() (compiled-in skills)
  -> MCP connections (batched: 3 local, 20 remote)
  -> Hooks config snapshot (frozen for session)
  -> main.tsx (React/Ink UI for REPL mode)
  -> REPL.tsx (prompt loop)
  -> query.ts:queryLoop() (conversation loop)
```

## Key Steps

**Settings**: Merges 6 sources (plugin < user < project < local < flag < policy). Migrations upgrade old formats.

**Feature Flags**: GrowthBook fetched from Anthropic API, cached to `~/.claude.json`. 6h refresh external, 20min Anthropic employees.

**Tool Registry**: `getAllBaseTools()` assembles built-in tools. `assembleToolPool()` merges with MCP tools, sorted for cache stability.

**System Prompt**: Static sections globally cacheable; dynamic sections per-session (except MCP instructions: every turn).

## Bare Mode (`--bare` / `CLAUDE_CODE_SIMPLE`)

Skips hooks, LSP, plugins, attribution, keychain, skill discovery. Only Bash + Read + Edit tools. ~30 skip gates in codebase.

# State Management
> Source: `06_tool_pipeline.md`, `19_api_layer.md`

## AppState Structure

Central mutable state with key fields: session identity (sessionId, deviceId), conversation messages, `toolPermissionContext` (immutable `DeepImmutable` snapshot), cost accumulator, MCP connections, hooks registry, active subagent tracking.

## ToolUseContext (Per-Turn)

40+ field object passed to every tool call: `messages[]`, `readFileState`, `abortController`, `contentReplacementState`, `toolDecisions` Map, and more.

## State Persistence

| What | Where | Survives |
|------|-------|----------|
| Transcript | `~/.claude/projects/<slug>/<sessionId>/` | Session resume |
| Session memory | `<sessionId>/session-memory/summary.md` | Compaction |
| Cost | Project config | Session resume |
| Tool results | `<sessionId>/tool-results/<id>.txt` | Current session |
| GlobalConfig | `~/.claude/.config.json` | Permanent |

## Subagent State

Subagents receive cloned `ToolUseContext` with filtered tools. `ContentReplacementState` is cloned so subagents see parent's persisted previews. Context modifiers from concurrent tools are queued and applied after batch completion.

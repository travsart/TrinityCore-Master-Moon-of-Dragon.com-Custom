# MCP OAuth PKCE
> Source: `12_mcp_client.md`

## ClaudeAuthProvider

Implements MCP SDK's `OAuthClientProvider` interface with:
- **PKCE**: Generates code verifier/challenge for each authorization flow
- **Secure storage**: Tokens in OS keychain via `getSecureStorage()`, keyed by `serverName|sha256(config)[:16]`
- **Lock-file serialization**: Prevents concurrent refreshes (max 5 retries)
- **Automatic refresh**: Proactive refresh with exponential backoff on 500/503/429

## OAuth Discovery (Cascading)

1. Configured URL (`oauth.authServerMetadataUrl`, must be HTTPS)
2. RFC 9728: `/.well-known/oauth-protected-resource` -> `authorization_servers[0]` -> RFC 8414
3. RFC 8414 fallback: path-aware discovery against MCP server URL

## Token Revocation (RFC 7009)

Revokes refresh token first (long-lived), then access token. Falls back to Bearer auth on 401 from non-compliant servers.

## Cross-App Access (XAA / SEP-990)

When `oauth.xaa` is true: IdP details from `settings.xaaIdp`, `performCrossAppAccess()` handles token exchange, cached `id_token` enables silent re-auth.

## Non-Standard Error Normalization

Handles servers (e.g., Slack) returning HTTP 200 with error JSON body. Normalizes `invalid_refresh_token`, `expired_refresh_token`, `token_expired` to `invalid_grant`.

## Claude.ai Proxy Auth

`createClaudeAiProxyFetch()` wraps fetch with OAuth bearer token, handles 401 with force-refresh, tracks sent token to avoid race conditions.

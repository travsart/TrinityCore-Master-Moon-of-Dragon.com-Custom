# MCP Transport Types
> Source: `12_mcp_client.md`

## 8 Transport Types

| Transport | Config Fields | Use Case |
|-----------|---------------|----------|
| `stdio` | `command`, `args[]`, `env{}` | Local process spawning (default) |
| `http` | `url`, `headers{}`, `oauth?` | MCP Streamable HTTP (primary remote) |
| `sse` | `url`, `headers{}`, `oauth?` | Legacy Server-Sent Events |
| `ws` | `url`, `headers{}` | WebSocket transport |
| `sse-ide` | `url`, `ideName` | IDE extension SSE (internal) |
| `ws-ide` | `url`, `ideName`, `authToken?` | IDE extension WebSocket (internal) |
| `sdk` | `name` | In-process SDK transport |
| `claudeai-proxy` | `url`, `id` | Claude.ai connector proxy |

If `type` is absent, `stdio` is assumed (backward compatibility).

## Environment Variable Expansion

Configs support `${VAR}` and `${VAR:-default}` syntax. Applied to: `command`, `args`, `env` (stdio); `url`, `headers` (remote).

## Batched Connection

Local (stdio/sdk): 3 concurrent. Remote (sse/http/ws): 20 concurrent. Both groups run in parallel.

## IDE Tool Filtering

Only 2 IDE tools exposed to model: `mcp__ide__executeCode` and `mcp__ide__getDiagnostics`.

## Tool Name Prefixing

MCP tools get `mcp__<server>__<tool>` names. Non-alphanumeric chars replaced with `_`. SDK servers can skip prefix via `CLAUDE_AGENT_SDK_MCP_NO_PREFIX`.

## Description Cap

Tool descriptions and server instructions capped at **2,048 characters** to prevent OpenAPI-generated servers from dumping 15-60KB into context.

# Upstream Proxy
> Source: `19_api_layer.md`, `12_mcp_client.md`

## Overview

Claude Code supports corporate proxy environments through standard HTTP/HTTPS proxy configuration. The API layer routes all traffic through configured proxies.

## Configuration

Proxies are configured via standard environment variables: `HTTP_PROXY`, `HTTPS_PROXY`, `NO_PROXY`. The `CLAUDE_CODE_CLIENT_CERT` env var provides client certificates for mutual TLS.

## Gateway Detection

The logging layer (`services/api/logging.ts`) fingerprints proxy gateways from response headers and base URL patterns. Detected gateways: LiteLLM, Helicone, Portkey, Cloudflare AI Gateway, Kong, Braintrust, Databricks.

## MCP Server Proxying

MCP HTTP hooks route through sandbox network proxy when sandboxing is enabled. SSRF guard blocks requests to private/internal IP addresses.

## Custom Headers

`ANTHROPIC_CUSTOM_HEADERS` env var adds custom headers (newline-separated) to all API requests. Useful for proxy auth.

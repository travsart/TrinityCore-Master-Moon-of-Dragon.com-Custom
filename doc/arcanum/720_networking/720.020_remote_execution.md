# Remote Execution
> Source: `17_bridge.md`, `21_feature_flags.md`

## Overview

Remote execution allows Claude Code to run on cloud infrastructure (CCR -- Claude Code Runner). Users interact via claude.ai/code, mobile apps, or IDE extensions while the CLI runs remotely.

## Session Types

| Mode | Behavior |
|------|----------|
| `single-session` | One session in cwd, bridge exits when it ends |
| `worktree` | Each session gets isolated git worktree |
| `same-dir` | Sessions share cwd (can conflict) |

Max concurrent sessions: 32. Session timeout: 24 hours (configurable via `--session-timeout`).

## Git Bundle Seeding

Remote sessions can receive the project via git bundle upload (`tengu_ccr_bundle_seed_enabled`). Max bundle size: 100MB (`tengu_ccr_bundle_max_bytes`). WIP stash capture preserves uncommitted changes.

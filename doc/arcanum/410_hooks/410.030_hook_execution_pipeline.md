# Hook Execution Pipeline
> Source: `09_hooks_system.md`

## Pipeline Flow

```
Settings + plugins + session hooks
  -> captureHooksConfigSnapshot() (frozen at startup)
  -> getMatchingHooks() (matcher + if-condition filtering)
  -> executeHooks() (parallel execution)
  -> [command | prompt | agent | http | callback | function]
  -> processHookJSONOutput() (structured results)
  -> AggregatedHookResult (yielded to caller)
```

## All Hooks Run in Parallel

Matching hooks are mapped to async generators and run via `all()` utility. Results yielded as each completes. Permission behavior precedence: **deny > ask > allow > passthrough**.

## 4 Hook Command Types

| Type | Execution | Default Timeout |
|------|-----------|-----------------|
| command (shell) | Spawn bash/powershell | 10 minutes |
| prompt (LLM) | Call small/fast model | 10 minutes |
| agent (verifier) | Spawn sub-agent with context | 60 seconds |
| http (webhook) | POST JSON to URL | 10 minutes |

## JSON Output Protocol

Hooks return structured JSON with optional fields: `continue`, `decision` (approve/block), `reason`, `systemMessage`, `hookSpecificOutput` (per-event: `permissionDecision`, `updatedInput`, `additionalContext`, `retry`).

## Async Hook Protocol

First stdout line `{"async": true}` backgrounds the hook. Config-based async: `async` and `asyncRewake` fields. Background hooks with exit 2 enqueue wake-up notifications.

## Timeouts

Default: 10 minutes. SessionEnd: 1.5 seconds. Status line/file suggestion: 5 seconds. Per-hook `timeout` field overrides defaults.

# Hook Events Catalog
> Source: `09_hooks_system.md`

## All 27 Events

**Tool lifecycle** (matcher = tool_name): `PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PermissionRequest`, `PermissionDenied`

**Session lifecycle**: `SessionStart` (matcher = source), `SessionEnd` (matcher = reason, 1.5s timeout), `Setup` (matcher = trigger)

**Turn boundary**: `UserPromptSubmit` (exit 2 = block prompt), `Stop` (exit 2 = continue conversation), `StopFailure` (fire-and-forget)

**Agent events** (matcher = agent_type): `SubagentStart`, `SubagentStop`

**Compaction** (matcher = trigger): `PreCompact` (stdout = custom instructions), `PostCompact`

**Team/task**: `TeammateIdle` (exit 2 = prevent idle), `TaskCreated`, `TaskCompleted` (exit 2 = prevent)

**MCP elicitation** (matcher = mcp_server_name): `Elicitation`, `ElicitationResult`

**Config/environment**: `ConfigChange` (matcher = source), `CwdChanged`, `FileChanged` (matcher = filenames), `InstructionsLoaded` (observability only)

**Worktree**: `WorktreeCreate` (stdout = worktree path), `WorktreeRemove`

**Notification** (matcher = notification_type): `Notification`

## Exit Code Protocol

| Code | Meaning |
|------|---------|
| 0 | Success -- stdout processed as output/context |
| 2 | Blocking -- stderr shown to model, operation blocked |
| Other | Non-blocking error -- stderr shown to user only |

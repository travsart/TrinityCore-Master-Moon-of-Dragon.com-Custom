# Skill Loading Pipeline
> Source: `11_skills_system.md`

## 8 Skill Sources (Merge Order)

1. **Managed** (`~/.anthropic/.claude/skills/`) -- policy-controlled
2. **User** (`~/.claude/skills/`) -- personal
3. **Project** (`.claude/skills/` per parent dir) -- project-scoped
4. **Additional** (`--add-dir .claude/skills/`) -- explicit CLI dirs
5. **Legacy** (`~/.claude/commands/`, `.claude/commands/`) -- deprecated
6. **Bundled** (compiled into binary) -- ship with CLI
7. **Plugin** (marketplace + built-in plugins) -- addon ecosystem
8. **MCP** (server prompts with `skill_md`) -- remote servers

First wins on name collision. Dynamic skills (discovered during file ops) merge before built-in commands.

## Conditional Activation (`paths:` Frontmatter)

Skills with `paths:` patterns are invisible until a file matching the pattern is touched. Uses gitignore-style glob via `ignore` library. Once activated, stays active for session.

## Dynamic Discovery

When files are read/written/edited, CC walks up from file parent to cwd checking for `.claude/skills/`. Gitignored directories skipped. Deepest-first precedence.

## 6 Cache Layers

| Cache | Cleared By |
|-------|------------|
| `getSkillDirCommands` | `clearSkillCaches()` |
| `loadAllCommands` | `clearCommandMemoizationCaches()` |
| `getSkillToolCommands` | `clearCommandMemoizationCaches()` |
| `getSlashCommandToolSkills` | `clearCommandMemoizationCaches()` |
| `getPrompt` | `clearPromptCache()` |
| `sentSkillNames` | `resetSentSkillNames()` |

Chokidar watches skill directories with 300ms debounce for live reload.

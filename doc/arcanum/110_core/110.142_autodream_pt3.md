### Completion Notification

When dreaming completes and files were touched:
```typescript
if (dreamState.filesTouched.length > 0) {
  appendSystemMessage({
    ...createMemorySavedMessage(dreamState.filesTouched),
    verb: 'Improved',
  })
}
```

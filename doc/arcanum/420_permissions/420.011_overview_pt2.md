## Interesting Findings

**Deny always wins.** A deny rule from any source overrides any number of allow rules. There is no mechanism to override a deny rule except removing it.

**Safety checks are bypass-immune.** Writes to `.git/`, `.claude/`, `.bashrc`, and other sensitive paths always prompt, even in `bypassPermissions` mode. This is enforced by the `safetyCheck` decision reason type.

**MCP server-level matching.** The rule `mcp__server1` as an allow rule auto-allows ALL tools from that server. This is a convenience feature but means granting blanket trust to an MCP server.

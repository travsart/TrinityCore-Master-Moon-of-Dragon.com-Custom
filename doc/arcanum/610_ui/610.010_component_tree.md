# Component Tree
> Source: `22_ui_renderer.md`, `20_messages_pipeline.md`

## Overview

Claude Code's UI is built with React and Ink (React for terminals). The component tree renders in the terminal using a custom reconciler that translates React elements to Yoga layout nodes.

## Key Components

**PromptInput** -- User input handling with vim/normal mode, autocomplete for `/` commands and `@` file mentions, shift+enter for multi-line.

**Message Rendering** -- Assistant messages, tool calls, tool results, thinking blocks. Each rendered with appropriate formatting and syntax highlighting.

**StructuredDiff** -- File diff rendering with before/after comparison, line numbers, and syntax highlighting.

**Permission Dialogs** -- `TrustDialog` (first-run workspace trust), `ToolUseConfirm` (per-tool approval with allow/deny/always options).

**Agent Status** -- Spinner tree or pills showing active subagents and their progress. Controlled by `showSpinnerTree` setting.

**Settings UI** -- `/config` panel with tabs for settings, permissions, MCP servers, hooks, and feature flag overrides (ant-only).

## Rendering Pipeline

1. React components declare layout via JSX props
2. Custom reconciler creates Yoga nodes
3. `yogaNode.calculateLayout()` computes positions
4. Renderer walks DOM tree, places content in screen buffer
5. Differential rendering only updates changed regions

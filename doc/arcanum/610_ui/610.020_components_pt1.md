# Key UI Components -- Arcanum Wiki

## Overview

Claude Code's UI is built from React components rendered via Ink (React for terminals). The component tree starts with `App.tsx` and branches into specialized components for prompt input, tool diffs, permission dialogs, progress indicators, context visualization, and more. This article covers the most architecturally significant components.

## How It Works

### App Component

`src/components/App.tsx` is the root component. It sets up the main layout, routes between screens, and manages top-level state like the current conversation, active tools, and background tasks.

### PromptInput

The prompt input component handles user text entry with features including:
- Multi-line editing with cursor navigation
- History recall (up/down arrows)
- Tab completion for slash commands and file paths
- Paste detection and handling
- Keyboard shortcut processing (Escape, Ctrl+C, etc.)

The input is built on `BaseTextInput.tsx` which provides the core text editing primitives.

### FileEditToolDiff

`FileEditToolDiff.tsx` renders inline diffs for file edit operations. It shows before/after content with syntax highlighting, line numbers, and color-coded additions/deletions. This is one of the most visually complex components in the UI.

### Permission Dialogs

Multiple permission-related components handle different scenarios:
- `BypassPermissionsModeDialog.tsx` -- Confirmation when entering bypass mode
- `AutoModeOptInDialog.tsx` -- Opt-in for auto mode
- `ToolUseConfirm` (in the REPL) -- The standard allow/deny/always-allow permission prompt

Permission dialogs support the 4-way race (user, bridge, channel, hooks+classifier) described in the permissions system.

### Background Tasks

`BashModeProgress.tsx` and `AgentProgressLine.tsx` show progress for running Bash commands and agent tasks. The `DevBar.tsx` component provides a developer toolbar with token counts, cache metrics, and model information.

### Context Visualization

`ContextVisualization.tsx` renders the token usage breakdown from the `/context` command as a visual grid, showing how the context window is allocated across system prompt, tools, memory, and conversation messages.

### CompactSummary

`CompactSummary.tsx` displays the compaction summary in a formatted view, showing what was preserved and what was dropped during auto-compact or manual `/compact` operations.

### Coordinator Status

`CoordinatorAgentStatus.tsx` shows the status of coordinator mode workers, including their current state (running, idle, completed), tool counts, and token usage.

### Export Dialog

`ExportDialog.tsx` provides the UI for exporting conversation transcripts in various formats.

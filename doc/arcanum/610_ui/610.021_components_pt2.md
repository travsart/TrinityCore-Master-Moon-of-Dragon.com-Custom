## Interesting Findings

**The component directory is massive.** Over 80 component files exist, covering everything from `ApproveApiKey.tsx` to `FeedbackSurvey/` to `ClaudeInChromeOnboarding.tsx`. The UI is far more complex than a typical CLI tool.

**Custom select components.** `CustomSelect/` provides a terminal-native dropdown menu system, replacing Ink's built-in select which was too limited for Claude Code's needs.

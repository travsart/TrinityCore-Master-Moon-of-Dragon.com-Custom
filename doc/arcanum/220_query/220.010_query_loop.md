# The Query Loop
> Source: `19_api_layer.md`, `20_messages_pipeline.md`

## Overview

`queryLoop()` in `src/query.ts` (~1,700 lines) is an infinite `while(true)` async generator that orchestrates every turn of conversation.

## Per-Iteration Phases

1. **Slice**: `getMessagesAfterCompactBoundary()` -- window to post-compact
2. **Budget**: `applyToolResultBudget()` -- persist oversized results to disk
3. **Snip**: Remove old history segments (feature-gated)
4. **Microcompact**: Strip stale thinking blocks, clear old tool results
5. **Context collapse**: Collapse old tool result regions (feature-gated)
6. **System prompt**: `appendSystemContext()` adds git status
7. **Auto-compact**: Full summary if over token threshold
8. **Blocking limit check**: Prevent API call at hard limit
9. **API call**: `callModel()` with `prependUserContext()` for CLAUDE.md
10. **Stream**: Process SSE events, yield assistant messages
11. **Tool execution**: `StreamingToolExecutor` or sequential `runTools()`
12. **Attachments**: `getAttachmentMessages()` (~30 providers concurrently)
13. **Continue or terminal**: Based on tool_use presence, max turns, budget

## Max Output Recovery

Limited to 3 attempts. On `max_tokens` or context overflow, escalates to 64K or triggers reactive compact.

## Task Budget

`taskBudgetRemaining` decrements across compaction boundaries. Post-compact, `remaining` is sent to tell the server about pre-compact usage.

# Response Streaming
> Source: `19_api_layer.md`

## Raw Stream (Not SDK's BetaMessageStream)

Claude Code uses raw streams to avoid O(n^2) partial JSON parsing. The SDK's `BetaMessageStream` calls `partialParse()` on every delta -- unnecessary overhead.

## SSE Event Processing

| Event | Action |
|-------|--------|
| `message_start` | Capture `partialMessage`, record TTFB |
| `content_block_start` | Init block by type (text, tool_use, thinking) |
| `content_block_delta` | Accumulate: text appended, tool JSON accumulated as string |
| `content_block_stop` | Parse complete block, yield `AssistantMessage` |
| `message_delta` | Final usage/stop_reason, update cost tracking |

Tool inputs are accumulated as raw JSON strings during streaming, parsed at `content_block_stop`.

## Non-Streaming Fallback

When streaming fails (any error except user abort), falls back to non-streaming. Timeout: 120s remote, 300s local. Max tokens capped at 64K for non-streaming.

## Stream Watchdog

Optional idle timeout (`CLAUDE_ENABLE_STREAM_WATCHDOG`): kills hung streams after 90s of silence. Warning fires at 45s. Stall detection independently logs any >30s gap between chunks.

## Stream Resource Cleanup

`releaseStreamResources()` explicitly cancels Response body and aborts stream controller. Native TLS/socket buffers live outside V8 heap and leak without explicit cleanup.

# Usage Tracking
> Source: `19_api_layer.md`, `03_context_window.md`

## Cost Tracking (`cost-tracker.ts`)

Per-request cost calculated at `message_delta` using `calculateUSDCost()`. Pricing tiers:

| Tier | Input/Mtok | Output/Mtok | Models |
|------|-----------|------------|--------|
| COST_TIER_3_15 | \ | \5 | All Sonnet variants |
| COST_TIER_5_25 | \ | \5 | Opus 4.5, Opus 4.6 |
| COST_TIER_30_150 | \0 | \50 | Opus 4.6 fast mode |

Cache: write = 1.25x input, read = 0.1x input. Web search: \/usr/bin/bash.01/request.

## Session Persistence

Costs saved to project config (`lastCost`, `lastAPIDuration`, `lastModelUsage`) and restored on session resume.

## Token Budget Feature

Users can request specific budgets: `+500k`, `use 2M tokens`. Parsed into raw counts. Produces continuation messages like: "Stopped at 87% of token target (435K / 500K). Keep working."

## Commands

| Command | Scope | Description |
|---------|-------|-------------|
| `/cost` | Session | Show cost and duration (hidden for subscribers) |
| `/usage` | Plan | Show plan usage limits (claude.ai only) |
| `/extra-usage` | Plan | Configure extra usage when limits hit |
| `/stats` | Session | Usage statistics |

# Rate Limiting
> Source: `19_api_layer.md`, `services/api/withRetry.ts`

## Retry Logic

Claude Code wraps every API call with `withRetry()` (29KB). Key parameters:
- **MAX_RETRIES**: 10 (configurable via `CLAUDE_CODE_MAX_RETRIES`)
- **BASE_DELAY**: 500ms with exponential backoff (max 32s, jitter 25%)
- **Persistent mode**: Up to 5-minute backoff, 6-hour reset cap

## Error Handling by Status

| Status | Action |
|--------|--------|
| 401 | Clear API key cache, retry with OAuth refresh |
| 429 | Retry for non-subscriber/enterprise; NOT for Max/Pro |
| 529 (overloaded) | Retry foreground; drop background immediately |
| 5xx | Always retry |

## 529 Cascade Protection

Background queries (summaries, titles, classifiers) bail immediately on 529 to avoid amplifying overload. Only foreground sources retry.

## Model Fallback

After 3 consecutive 529s on Opus, throws `FallbackTriggeredError` which triggers switch to Sonnet.

## Fast Mode Rate Limiting

On 429/529 during fast mode: short retry-after sleeps and retries; long retry-after triggers 30-minute cooldown switching to standard speed.
